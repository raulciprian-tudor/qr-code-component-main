# QR Code Component
## Project

The page displays a QR code and short message in a centered card. It is built with plain HTML and CSS, with no build tools or JavaScript required.

## Skills to practice

- Structuring content with HTML
- Styling and aligning elements with CSS and Flexbox
- Matching a visual design through spacing, color, and typography
- Checking the layout at different screen sizes and improving accessibility

## Run locally

Open `index.html` in a web browser. The Outfit typeface is loaded from Google Fonts, so an internet connection is needed for that font.
